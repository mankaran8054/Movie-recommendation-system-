# Movie Recommendation System

## Project Description
A movie recommendation system that recommends movies
to users based on their preferences and movie data.

## Objectives
- Recommend relevant movies to users
- Use movie features/user preferences for recommendations
- Provide an easy-to-use interface

## Planned Features
- Movie search
- Movie recommendations
- User preferences
- Recommendation algorithm
- User interface

## Technologies
- Python
- Machine Learning
- Pandas
- Scikit-learn
- Streamlit 

## Project Status
Currently under development
